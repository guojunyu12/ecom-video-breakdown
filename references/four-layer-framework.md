# 四层拆解框架

| 层 | 要回答的问题 | 输出 |
|---|---|---|
| L1 策略层 | 卖给谁？主卖点是哪 1 个？内容形式（口播/开箱/测评/对比/剧情/混剪/工厂源头/达人种草）？情绪基调（吐槽/安利/冷静测评/紧迫）？ | 一句话定位：「给【人群】看，在【场景】下，用【形式】证明【主卖点】」 |
| L2 节拍层 | 套的哪种结构模板？每段几秒、占比多少？卖点按什么顺序出现、各用什么证明？ | 节拍时间轴：`钩子 0–3s → 痛点 3–6s → …` + 模板名 |
| L3 镜头层 | 每个镜头在干什么？景别怎么分配？节奏快慢？ | 分镜表 + 镜头数 + ASL（总时长 ÷ 镜头数，来自 meta.json） |
| L4 元素层 | 前 3 秒靠什么留人？首帧单独截出来能不能抓人？花字是否独立承担信息？产品第几秒露出？CTA 在哪、什么形式、给了什么「现在买」的理由？ | 钩子分析、花字清单、静音可看性评分、CTA 分析 |

## 分镜表字段
| # | 时间码 | 时长 | 景别 | 画面 | 口播 | 花字/字幕 | 作用（钩子/痛点/展示/证明/信任/促单） |

景别：远景 / 全景 / 中景 / 近景 / 特写 / 大特写 / 手部特写 / 屏幕录制 / 第一人称 POV。

## 静音可看性（新）
只看 `ocr.json` 里的文字层和画面，不听声音，能否回答：
1. **卖什么**（品类/产品是什么）
2. **为什么买**（主卖点或痛点）
3. **去哪买 / 怎么买**（小黄车、链接、直播间）

每答出一问得 1 分，满分 3 分。另记：花字总条数、前 3 秒是否有花字、花字是否只是逐字复述口播。

## 多条爆款 → 共性公式
逐条拆完以后做对照表：结构模板、钩子类型、主卖点证明方式、ASL、产品露出秒数、CTA 形式。出现在多数样本里的才算「共性」，只在 1 条里出现的标「个例」。

## 不可迁移因素（单独列出，不计入复刻）
达人人设与粉丝基础、品牌知名度、投流预算、热点或节日时机、原 BGM 版权、原台词与原画面、无法证明的数据（销量、好评数、检测结论）。
