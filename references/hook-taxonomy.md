# 前 3 秒钩子分类

前 3 秒 = **文案钩子 × 画面钩子 × 声音钩子**。分析时三条线分开写，再看是否同时强化同一个信息。
（文案和画面分类参考了 huashu-douyin-script（MIT）的 6+6 分类，并做了改写和扩充。）

## 文案钩子
| 类型 | 说明 | 写法骨架 |
|---|---|---|
| 痛点 | 直接说出目标人群的麻烦 | 「【场景】又【问题】了？」 |
| 反常识 | 打破常识，制造冲突 | 「别再【常见做法】了」 |
| 结果先行 | 先给效果，再讲原因 | 「【效果】，我只做了一件事」 |
| 人群点名 | 让观众觉得「说的就是我」 | 「【人群】一定要看」 |
| 价格反差 | 价格低到出乎意料，或买一送多 | 「【价格】买到【价值】」 |
| 悬念 | 留一个缺口 | 「千万别【动作】，除非…」 |
| 数据 | 用具体数字（必须有证据） | 「【数字】【单位】，【结论】」 |
| 场景代入 | 还原一个具体生活画面 | 「每次【场景】前，我都…」 |

## 画面钩子
| 类型 | 说明 |
|---|---|
| 前后对比 / 画面突变 | before→after，颜色、状态瞬间变化 |
| 动作冲击 | 摔、砸、倒、撕、挤、夸张表情 |
| 产品堆叠 | 大量产品入镜，占便宜感 |
| 大字花字 | 一句大字报直接给信息，0.5 秒读完 |
| 第一人称 POV | 手持展示、俯拍桌面、直视镜头 |
| 视觉奇观 | 微距、特效、少见画面 |
| 痛点实拍 | 直接拍问题本身（油污、起球、漏水） |

## 声音钩子
第一句话的语气（惊讶/吐槽/命令）、音效（撞击/提示音）、BGM 切入或卡点、反常的安静。

## 检查项
- 首帧：暂停在第 0 秒，单独截出来能不能让人停下？有没有用 logo 片头？
- 产品或痛点画面是否在第一帧出现，还是刻意延后露出（软植入）？
- 钩子和后面的卖点有没有关系（为了留人硬造的悬念会拖累转化）？
- 前 3 秒有没有花字，静音能不能看懂？
