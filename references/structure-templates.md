# 抖音带货常见结构模板

骨架共识：**吸引 → 信任 → 行动**。下面是常见的细分模板，节拍层拆解时先判断套的是哪一个，再写各段秒数。

| 模板 | 节拍 | 适合 |
|---|---|---|
| 5 段式（种草标准型） | 钩子 → 痛点 → 卖点（带证明）→ 信任 → 促单 | 大多数日用、美妆、食品 |
| 4 段式 | 抛需求（0–3s）→ 给方案 → 验信任 → 催下单（最后 3–5s） | 30s 左右口播 |
| 对比型 | 钩子 → before → 使用过程 → after → 促单 | 清洁、护肤、收纳等效果可见的品类 |
| 产品演示型 | 钩子 → 产品亮相 → 使用演示 → 价格锚定 → 促单 | 千川信息流常见，节奏快 |
| 测评型 | 钩子 → 我的经历 → 开箱 → 卖点逐个实测 → 缺点/适合谁 → 促单 | 3C、家电、高客单价 |
| 剧情型 | 冲突 → 升级 → 产品解决 → 反转/回报 → 促单 | 情绪类、礼品类 |
| 源头/工厂型 | 产地或工厂画面 → 工艺/原料 → 价格对比 → 促单 | 农产品、服饰、源头货 |

## 经验规则（行业通用说法，非平台官方标准）
- 整条只主打 **一个下单理由**，其余卖点是补充。
- 每个卖点都要有 **能拍出来的证明画面**（演示、对比、细节特写），光说不演不算卖点。
- 中文口播约 4–5 字/秒，台词时长 ≈ 字数 ÷ 4.5（参考 xianyu110/ecommerce-video-skills，MIT）。
- CTA 要有明确动作（点小黄车/左下角链接/进直播间）+ 一个现在买的理由（限时、赠品、运费险）；「点赞关注」不是带货 CTA。
