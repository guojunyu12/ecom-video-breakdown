# 视频角色识别规则

目的：搞清楚每条视频是「爆款（参考）」还是「自家（被诊断）」。认错一次，整份对比报告都会反过来。

## 禁止
- 根据上传顺序猜（「第一条通常是爆款」）
- 根据水印、账号名、画质、清晰度、拍摄质量、点赞截图去猜
- 问完一次以后再反复确认

## 判定顺序
1. **用户消息明确说了** → 用。例：「第2条是我们店的」「后面两条是竞品」。
2. **文件名或文件夹**：
   - `爆款_` / `竞品_` / `对标_` / 位于 `爆款/` 文件夹 → 爆款
   - `自家_` / `我的_` / `本店_` / 位于 `自家/` 文件夹 → 自家
3. **都没有** → 运行 `scripts/probe_frames.py`，展示每条视频的首帧图 + 时长 + 文件名，只问一次：

> 哪条是你家的？
> - ① 文件名 / 时长 / 首帧
> - ② …
> - 都是爆款，只拆不对比

如果只有 1 条视频且用户说「拆解」，默认它是爆款，不用问；用户说「帮我看看我的视频」，默认它是自家。如果只有 1 条视频而且意图不明，仍然问一次。

## 锁定标签
- 爆款按出现顺序命名为 **爆款A、爆款B…**，自家视频命名为 **自家1、自家2…**
- 在报告开头列出「标签 ↔ 文件名」对照表，之后全程只用标签
- 用户中途纠正 → 以纠正为准，重新生成受影响的部分，并说明改了什么
